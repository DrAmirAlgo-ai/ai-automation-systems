# TechCare — Clinical RAG & Healthcare Platform

Clinical Decision Support & Healthcare Management System:
- **Medical RAG Engine:** Indexes PubMed research, clinical practice guidelines, and localized drug registries (Egyptian market).
- **Inference & Grounding:** Integrated with local LLMs (Qwen 3.5 9B via LM Studio) and cloud APIs (Gemini Flash) with strict source citation.
- **Backend Architecture:** Built with C# / .NET, featuring JWT authentication, role-based clinic controls, and automated patient queue management.
