# ContentForge — AI Content Automation Pipeline

End-to-end automated media production pipeline:
- **Script Generation:** Structured scripts generated via LLMs (Qwen / Ollama / LM Studio).
- **Image Generation:** Visual assets generated via ComfyUI using FLUX models.
- **Video & Motion:** Wan 2.2 Image-to-Video engine for scene animation.
- **Audio & Assembly:** Edge-TTS / ElevenLabs integration, synced subtitles, and automated assembly via FFmpeg.
