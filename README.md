# Production AI Systems & Automation Portfolio

A collection of end-to-end AI automation systems, multi-agent pipelines, and domain-specific platforms built from specification to deployment.

---

## Core Systems Overview

### 1. [ContentForge — AI Content Automation Pipeline](https://github.com/DrAmirAlgo-ai/contentforge-ai-video-pipeline)
- **Domain:** Media Production & Content Automation
- **Stack:** ComfyUI (FLUX), Wan 2.2 (Image-to-Video), Local LLMs (Qwen), ElevenLabs, FFmpeg.
- **Key Capability:** Converts ideas into complete animated videos with synced voiceover and subtitles without manual editing.

### 2. [TechCare — Clinic Management System with AI Assistant](https://github.com/DrAmirAlgo-ai/techcare-clinic-management)
- **Domain:** Healthcare & Clinic Management
- **Stack:** C# / .NET, React, SQLite / PostgreSQL (pgvector), Local Qwen (LM Studio)
- **Key Capability:** Multi-clinic management (smart queue, online booking, billing, owner panel) plus a medical assistant that answers from a medical library with source attribution.

### 3. [AI Outbound & Lead Qualification System](https://github.com/DrAmirAlgo-ai/ai-outbound-lead-qualification)
- **Domain:** Process Automation & Sales Operations
- **Stack:** Python, LLM Evaluation Pipelines, Zoho SMTP, Model Failover Strategies.
- **Key Capability:** Ingestion, automated qualification scoring, and throttled multi-channel outreach tracking.

## Technical Capabilities & Method
- **Methodology:** AI-assisted software development using coding agents (Claude Code) — owning problems end-to-end from architectural spec to deployed validation.
- **Infrastructure:** Hybrid local-first (Local GPUs, LM Studio, ComfyUI, Ollama) and scalable cloud compute (Runpod, Gemini APIs).
- **Core Focus:** Agentic system design, RAG pipelines, workflow automation, and backend integration.
