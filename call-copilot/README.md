# Call Copilot — Real-Time AI Live Translation & Response Agent

Real-time assistant for technical and engineering calls:
- **Speech Pipeline:** Real-time speech-to-text recognition with bidirectional interim and final stream handling.
- **Agentic Behavior Engine:** Configurable identity and negotiation behavior engine that enforces strategic conversational rules.
- **Layered Memory:** Sliding window of recent interactions coupled with rolling contextual summaries.
- **Hybrid Inference:** Multi-tier fallback between local models (Qwen 3.5 via LM Studio) and Gemini API with automated quota failover.
